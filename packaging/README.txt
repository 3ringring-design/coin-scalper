=== Coin Scalper 실행 방법 ===

지금은 모의매매 전용이에요. 실제 돈은 나가지 않아요.

1) 백테스트 (최근 30일 성과 확인)
   Backtest.exe 를 더블클릭하세요.
   결과가 나오면 화면을 캡처하거나 복사해서 Claude에게 보내주세요.

2) 모의매매 시작
   CoinScalper.exe 를 더블클릭하세요.
   검은 창이 열리고 "모의매매 시작"이 보이면 정상이에요.
   창을 닫거나 Ctrl + C 를 누르면 꺼져요. 다시 켜면 이어서 진행돼요.

3) 24시간 돌리기
   - 윈도우 설정 > 시스템 > 전원 > 절전 모드를 "안 함" 으로 바꾸세요.
   - 컴퓨터를 켤 때 자동 실행하려면:
     윈도우키 + R > shell:startup 입력 > 열린 폴더에
     CoinScalper.exe 의 "바로 가기"를 넣어두세요.

처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있어요.
서명 안 된 프로그램이라 그런 거예요. "추가 정보" > "실행" 을 누르면 돼요.

생기는 파일
   logs\bot.log              실행 기록
   state\paper_state.json    가상 잔고와 보유 코인 (지우면 처음부터 다시 시작)
   state\paper_trades.csv    거래 내역 (엑셀로 열 수 있어요)
   config.yaml               설정 (메모장으로 수정 가능)

텔레그램 알림을 받고 싶으면 .env.example 을 .env 로 이름을 바꾸고 값을 채우세요.
