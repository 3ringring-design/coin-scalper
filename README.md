# 🪙 Coin Scalper

바이낸스 현물 5분봉 단타 봇. 지금은 **모의매매(paper) 전용**이라 실제 주문은 나가지 않습니다.
공개 시세만 쓰기 때문에 API 키 없이 바로 돌려볼 수 있어요.

## 🌐 웹으로 실행하기 (설치 없음)

👉 **https://3ringring-design.github.io/coin-scalper/**

- **⚡ 세팅하고 시작** 버튼 하나로 추천 포트폴리오(투매 반등 +횡보장 40% · 눌림목 반등 30% · 채널 돌파 +추세장 30%, 모두 1h, 선물 롱+숏 1배)가 세팅되고 바로 실행돼요.
- 크롬으로 열고 **▶ 시작**을 누르면 모의매매가 돌아가요. 탭을 열어두는 동안 계속 실행돼요.
- **포트폴리오 모드**: 전략 여러 개가 자금 비중대로 같은 계좌에서 동시에 매매해요. 연구실 순위표에서 ☐로 담으면 조합 결과(합산 수익·낙폭)를 보고 그대로 적용할 수 있어요.
- **전략 연구실** 탭: 전략 8개 × 설정 241조합. **롤링 검증**(학습 60일 → 검증 30일을 한 칸씩 밀며 반복)으로 몇 구간에서 통했는지 보여줘요. 한 번 나누기(70/30)도 선택 가능. 마음에 드는 걸 눌러 실시간에 바로 적용.
- **백테스트** 탭에서 현재 전략의 최근 N일 성과를 확인할 수 있어요.
- 잔고·거래내역은 브라우저에 저장돼서 새로고침하거나 다시 열어도 이어서 진행돼요.
- **📋 상황 복사** 버튼을 누르고 Claude 채팅에 붙여넣으면 피드백하기 쉬워요.
- 시세는 `data-api.binance.vision`(바이낸스 공식 시세 전용 주소)을 먼저 쓰고, 막히면 다른 주소로 자동 전환해요.

`main`에 코드가 올라오면 1~2분 뒤 같은 주소에 자동 반영돼요(`.github/workflows/deploy-web.yml`).
웹 코드는 `web/index.html`(화면)과 `web/core.js`(지표·전략·백테스트 엔진)예요. `node tests/web_core.test.js`로 검증해요.

**활성 전략 (연구실 대상)** — 여러 번의 롤링 검증에서 반복해서 살아남은 것만

| 전략 | 아이디어 |
|---|---|
| 투매 반등 | 연속 음봉 급락 + 거래량 폭발 후 첫 양봉에서 단기 반등 (횡보장 필터와 궁합이 좋음) |
| 눌림목 반등 (ATR) | 상승추세 속 볼린저 하단 이탈 + RSI 과매도, ATR 기반 익절·손절 |
| 스퀴즈 돌파 | 볼린저 폭이 최저로 좁아진 직후 거래량 동반 돌파, 추적손절 |
| 채널 돌파 + ADX | N봉 신고가 돌파 + ADX 추세 강도 (추세장 예비) |

**보관 (코드는 남아 있고 예전 설정은 동작, 연구실에서는 제외)**: 기존 v1, StochRSI, VWAP, MACD, 장중 모멘텀, 시간대 효과, 변동성 돌파, 상황별 앙상블 — 비용을 못 넘거나 특정 시기에만 통했어요. 5분봉도 연구실에서 뺐어요(비용을 한 번도 못 넘음).

모든 전략에 공통 필터 두 가지를 켤 수 있어요.
- **시장 상태**(카우프만 효율비율): 추세형은 추세장에서만, 되돌림형은 횡보장에서만.
- **봉 내부 확인**(체결강도 = 시장가 매수 비율, 봉 마감 위치): 추세형은 공격적 매수로 위에서 마감한 돌파만, 되돌림형은 공격적 매도가 쏟아진 뒤 매수가 받아낸 봉만.
연구실에서 기본 / +시장 상태 / +봉 내부 / 둘 다 4가지를 한 번에 롤링 검증해요.

**분할 매수·분할 매도** (모든 전략 옵션, 총 투자금과 최초 손절선은 그대로라 최악 손실이 늘지 않음)
- 분할 매수: 신호에 50%만 진입. 되돌림형은 ATR 1배 더 유리한 가격(손절선 안쪽)에서 나머지, 추세형은 맞는 방향으로 ATR 1배 가면 나머지(불타기 — 손절 기준을 올려 최악 손실 유지).
- 분할 매도: 평단 대비 ATR 1.5배에서 절반 익절, 남은 절반은 손절선을 본전으로.
- 연구실 '분할 비교'로 기본 / 분할 매수 / 분할 매도 / 둘 다를 롤링 검증.

**수익 구조 옵션** (모든 전략 공통, 기본은 꺼짐 — 연구실 '추가 비교'로 검증)
- **손절 거리 기준 투자 금액**: 손절에 걸리면 자산의 N%만 잃도록 포지션 크기를 역산 (설정 탭 '투자 금액 방식'). 연구실에선 '수익÷낙폭'으로 고정 방식과 비교.
- **롱/숏 손익 분리**: 연구실 표에 롱 거래 손익과 숏 거래 손익을 따로 표시.
- **큰 방향 필터**: 30일 추세선 위에서는 롱만, 아래에서는 숏만.
- **러너**: 분할 익절 뒤 남은 절반은 익절선·신호 청산 없이 추적손절(3 ATR)로만 → 큰 추세를 끝까지.
- **지정가 진입**: 신호 뒤 0.25 ATR 더 좋은 가격에 지정가로 3봉 대기, 안 닿으면 취소. 지정가 진입·익절·분할 익절은 메이커 수수료(선물 0.02%, 슬리피지 없음).
연구실은 필터 버전을 같이 비교하고, 상세 화면에 **익절·손절 지도**(모든 검증 구간 평균)를 보여줘요.

조사했지만 넣지 않은 것: 15분 이하 역추세(효과는 있지만 비용을 못 넘음 — Kitron·Wengrowicz 2026), 초 단위 호가 불균형(호가창·저지연 서버 필요 — Bieganowski·Ślepaczuk 2026).

**선물·숏·레버리지 (모의)**
- 숏 신호는 가격을 뒤집은 차트(1/가격)에 같은 전략을 적용해서 만들어요. 8개 전략 모두 롱·숏 양방향 가능.
- 비용 모드: 현물(0.1%+0.05%) · 선물 시장가(0.05%+0.03%) · 선물 지정가(0.02%, 낙관적) · 비용 없음(진단용). 선물은 8시간마다 펀딩비 0.01% 반영.
- 격리 마진 기준 강제청산가 = 진입가 × (1 ∓ 1/레버리지 ± 0.5%). 손절보다 먼저 닿으면 증거금 전액 손실.
- 연구실 상세에서 같은 전략을 1·2·3·5·10·20배로 돌린 결과(수익률·낙폭·강제청산)를 보여줘요.
- 시세는 현물 데이터로 대신 계산해요(선물과 거의 같이 움직임). 수수료는 실제 계정 등급에 맞게 설정 탭에서 바꾸세요.

> 파이썬 버전(`run.py`)은 v1 전략·현물만 있어요.

> 24시간 돌리려면 PC 절전 모드를 "안 함"으로 두고 탭을 닫지 마세요. 백그라운드 탭에서도 동작하지만, 화면 꺼짐 방지를 켜두면 더 안정적이에요.

## 전략 한눈에 보기

상승추세 속 **눌림목 평균회귀** (롱 전용)

| 구분 | 조건 |
|---|---|
| 진입 | 종가 > EMA200 **그리고** 종가 < 볼린저 하단(20, 2σ) **그리고** RSI(14) < 35 |
| 익절 | +1.0% |
| 손절 | −0.6% |
| 중심선 복귀 | 볼린저 중심선 회복 + 수익 0.3% 이상이면 정리 |
| 시간 청산 | 24캔들(2시간) 지나면 정리 |

모든 숫자는 `config.yaml`에서 바꿀 수 있어요. 수수료(0.1%×2)와 슬리피지를 반영해서 계산합니다.

## 설치 (처음 한 번)

Python 3.10 이상 필요.

```bash
cd coin-scalper
python -m venv .venv
# 윈도우: .venv\Scripts\activate    맥/리눅스: source .venv/bin/activate
pip install -r requirements.txt
```

## 1. 백테스트로 먼저 확인

```bash
python backtest.py --days 30              # config의 모든 종목
python backtest.py --symbol ETH/USDT --days 90
```

전략 수익률, 승률, 최대낙폭, 그냥 보유했을 때와 비교를 보여주고 거래내역을 `backtest_results/`에 저장해요.

## 2. 모의매매 실행

```bash
python run.py
```

- 로그: `logs/bot.log`
- 잔고·보유 포지션: `state/paper_state.json` (껐다 켜도 이어서 진행)
- 거래내역: `state/paper_trades.csv`
- 처음부터 다시 하려면 `state/` 폴더를 지우세요.

## 3. 집 PC에서 24시간 돌리기

- **윈도우**: `scripts\run_forever.bat` 더블클릭. 봇이 오류로 꺼져도 자동 재시작돼요.
  - 설정 → 시스템 → 전원 → **절전 모드: 안 함** 으로 바꿔두세요. PC가 잠들면 봇도 멈춰요.
  - 윈도우 업데이트 재부팅 대비: 작업 스케줄러에 "로그온 시 run_forever.bat 실행" 등록 추천.
- **맥/리눅스**: `bash scripts/run_forever.sh` (맥은 자동으로 잠자기 방지)

## 4. 텔레그램 알림 (선택)

1. 텔레그램에서 `@BotFather` → `/newbot` → 토큰 받기
2. 만든 봇에게 아무 메시지 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates` 에서 `chat.id` 확인
3. `.env.example`을 `.env`로 복사하고 두 값을 채우기

매수·매도할 때마다 휴대폰으로 알림이 와요.
